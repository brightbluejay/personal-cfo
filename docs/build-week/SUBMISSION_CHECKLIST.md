# Submission Checklist

Use only evidence-backed statuses: `pass`, `fail`, or `manual check`.

## Product

- [ ] Fictional demo mode works from a clean setup
- [ ] Local ledger works
- [ ] Categorisation works with provenance
- [ ] Safe-to-spend calculation is deterministic and tested
- [ ] Debt snowball and avalanche are deterministic and tested
- [ ] GPT-5.6 use is meaningful and grounded
- [ ] External-service failure does not break the demo

## Repository

- [ ] Public-safe privacy scan completed
- [ ] Secret scan completed
- [ ] Licence selected
- [ ] README setup instructions verified
- [ ] `.env.example` contains placeholders only
- [ ] No user database or statements committed
- [ ] Third-party licences reviewed

## Codex evidence

- [ ] Majority of core functionality built in primary thread
- [ ] Build log completed honestly
- [ ] README explains Codex collaboration
- [ ] `/feedback` run manually in primary thread
- [ ] Session identifier copied to submission notes

## Demo and submission

- [ ] Demo script is under three minutes
- [ ] Working product shown
- [ ] Codex use explained
- [ ] GPT-5.6 use explained
- [ ] No private data or secrets visible
- [ ] Repository and testing links verified
